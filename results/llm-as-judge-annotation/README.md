# LLM Judge Annotating

`usage-guide.pdf` contains the guide that was used by the annotators, describing the used categories and commands.

`llm-judge-outputs--3sample/` contains the LLM judge-generated outputs on the sampled dataset.

`./annotation_agreement.py 3sample-annotator-1.json 3sample-annotator-2.json` can be used to verify the interannotator agreement.
 - `judge_accuracy.csv` contains the judge accuracies obtained by the script mentioned above.
